# Security Policy

## Reporting

Please report security issues privately to `security@hmsmiyu.com`.

Do not open a public issue for vulnerabilities involving authentication,
session tokens, encryption, sync integrity, or data exposure.

## Scope

- Go server under `server/`
- Flutter clients under `client/`
- Deployment templates under `deploy/`

## Not included in this repository

- Production keys or credentials
- Code-signing private keys
- Test databases or backups
- Internal operations documentation
